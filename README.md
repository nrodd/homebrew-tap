# homebrew-tap

Homebrew tap for [nrodd](https://github.com/nrodd)'s tools.

## Install

```sh
brew install nrodd/tap/rgboo
```

[`rgboo`](https://github.com/nrodd/rgboo) streams the RGBoo live broadcast to
your speakers with an animated terminal scene.
